# Simple Learning Algorithms

Implementing fundamental machine learning algorithms from scratch, following concepts from DeepLearning.AI course material.

## Contents

- `multi_linear_regression.ipynb` - Multivariate linear regression with gradient descent
- `logistic_regression Dataset 1.ipynb` - Logistic regression classifier (linear boundary)
- `logistic_regression Dataset 2.ipynb` - Logistic regression with polynomial features (non-linear boundary)

## Data

Datasets from the DeepLearning.AI course:
- `houses.txt` - Housing data for regression
- `ex2data1.txt`, `ex2data2.txt` - Classification datasets
